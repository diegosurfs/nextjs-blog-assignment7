---
title: 'When to Use Static Generation vs. Server-side Rendering'
date: '2020-01-02'
---

Static Generation and Server-side Rendering are two ways Next.js can pre-render pages.

Static Generation creates the page at build time. This is useful when the content does not need to change for every request.

Server-side Rendering creates the page when a request is made. This can be useful when the page needs current data.

Next.js allows developers to choose the best method for each page in an application.
